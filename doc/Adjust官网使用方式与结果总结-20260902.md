## 一、平台定位

Adjust 是一款 **移动应用归因（Attribution）与营销数据分析平台**，核心解决三个问题：

1. **用户从哪来**：追踪广告展示 → 点击 → 安装 → 应用内事件（注册、首存、复存等）的全链路归因；
2. **哪个渠道有效**：按渠道/国家/活动/广告组等维度对比获客表现；
3. **流量是否可信**：识别作弊点击、虚假安装、不可信设备等欺诈流量。

## 二、整体导航结构

登录后为四大产品模块（左侧导航栏）：

| 模块 | 功能 | 当前账号可用性 |
|---|---|---|
| **主页** | 应用卡片、Datascape 收藏、通知中心 | ✅ 可用 |
| **Datascape** | 数据分析中心（控制面板 + 报告） | ✅ 可用（核心） |
| **Campaign Lab** | 自定义链接、深度链接、链接调试工具 | ❌ 403 无权限 |

另有：账户设置（个人档案/密码/语言/API 识别码）、帮助中心、资源中心（57 条未读通知）。

## 三、核心使用方式

### 1. Datascape 控制面板（预置看板）

路径：`Datascape → 控制面板`，共 6 个预置看板 + 自定义看板：

- **概览**：KPI 卡片（安装量、广告支出、所有收入、平均 DAU）+ 表现概览（Top10 渠道）+ 实时表现报告 + 安装后同期群指标（ROAS/ROI/毛利）；
- **用户获取**：渠道获客漏斗分析；
- **应用营收**：变现收入分析；
- **SKAN**：iOS SKAdNetwork 归因看板；
- **保护**：反作弊看板（被拒安装概览、被拒交互、交互作弊、不受信任设备、分布监测、签名统计等 10 个组件）；
- **同期群分析**：留存率同期群表/图、表现趋势。

每个看板支持统一过滤器：**应用 / 日期范围（滚动）/ 对比 / 渠道源 / 国家地区 / UTC 偏移量**，任一组件可一键"作为报告打开"下钻。

### 2. Datascape 报告（自由分析，使用最重）

路径：`Datascape → 报告 → 所有报告`，当前账户下已有 **17+ 个共享报告**（如 Hatti-Daily、Play time日报-dsp汇总、事件查看-分平台、wanzhong竞价/合约、C2C-Report 等），均为团队成员创建并公开。

报告能力：

- **维度**：日期、渠道（network）、国家、平台、活动/广告组/创意（campaign/adgroup/creative）等，支持透视表视图；
- **指标**：展示、点击、安装、重新下载安装、自定义事件（Register / FirstDeposit / FirstBet / RecallDeposit）、同期群转化比率（0D/3D/7D）、留存率（D0/D1/D3/D7）、WAU 等；
- **操作**：编辑、收藏、分享、下载（导出）、定时发送、列筛选/热力图上色、按列排序；
- **典型用法**：按渠道监控"曝光→点击→安装→注册→首存"漏斗，计算 D0/D7 转化率，评估各投放渠道质量。

### 3. 应用管理（AppView）

路径：`AppView → 所有应用`，展示全部应用的 app token、类型、SDK 版本、近 7 天安装量及环比。当前组织内应用包括：

- 活跃：**Transsion**（SDK v4.38.3，7 日安装 119,729）、**appdownload**（80,265，-40.24%）、**Honor**（SDK v5.7.0）、**socialMediaActivity**（网页，3 个网页属性）、mayadownloadapp、gcashdownloadapp 等；
- 待激活（0 安装）：EGgame、Foodpanda、GooglePlay、Grab 等 10+ 个应用。

应用配置快捷菜单含：平台、事件、测试控制台、服务器回传、云储存上传、SDK 集成（当前账号下几乎全部禁用）。

### 4. Campaign Lab（投放工具箱）

含 **自定义链接**（生成带归因参数的投放链接）、**深度链接**（Deeplink 生成）、**链接调试工具**——当前账号 403 无权限。

### 2. 可产出的分析结论类型

- **渠道质量评估**：各渠道点击→安装转化率、注册率、首存率对比（如 0D 首存率区间 1.4%~1.9%，可定位高价值渠道）；
- **同期群留存**：D1/D3/D7 留存率，判断用户长期价值；
- **投放日报/周报**：报告支持定时发送与下载导出，可直接对接运营例会；
- **欺诈监测**：被拒安装率、点击注入、不受信任设备占比（概览中可见 Untrusted Devices 渠道 27,297 安装）；
- **API 取数**：账户设置中提供 API 识别码（API Token），可通过 Adjust Reporting API 自动化拉取数据。

## 五、使用流程小结

```
登录 → 主页查看应用/收藏报告
     → Datascape 控制面板：宏观 KPI、渠道表现、留存、反作弊
     → Datascape 报告：自定义维度/指标下钻，收藏/分享/导出/定时
     → Campaign Lab：生成投放链接与深度链接（需权限）
     → AppView：应用配置（事件映射、渠道对接、回传设置，需权限）
```
