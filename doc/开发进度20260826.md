```
demo.channel_daily_metrics

├── registrations  INT         注册用户数
├── fd_users       INT         FD 用户数（首次充钱）
├── fd_amount      NUMERIC     FD 金额（首次充钱金额）
├── rd_users       INT         RD 用户数（召回再充钱）
└── rd_amount      NUMERIC     RD 金额（召回充钱金额）

demo.channel_campaigns
├── campaign_no     TEXT        计划编号（如 CMP-Meta-app-dl）
├── ad_channel      TEXT        投放渠道
├── platform        TEXT        承接端
├── objective       TEXT        投放目标：拉新下载 / 首次充值 / 召回充值
├── campaign_name   TEXT        计划名称
├── status          TEXT        状态：active / paused
├── start_date      DATE        启动日期
├── daily_budget    NUMERIC     日预算（美元）
├── total_spend     NUMERIC     累计花费
├── downloads       INT         累计下载
├── registrations   INT         累计注册
├── fd_users        INT         累计 FD 用户
└── rd_users        INT         累计 RD 用户
```

## 五、预埋洞察设计

为确保数据分析、异常检测、深度研究链路均有"料"可挖，在数据中预埋了以下业务特征：

| 编号 | 预埋洞察 | 验证方式 |
|---|---|---|
| ① | **Meta 质高价贵**：CPM/CPI 最高（CPI≈$6.15），但 FD/RD 率最优，ROI≈1.35 最佳 | 聚合查询按渠道对比 |
| ② | **TikTok 量大质低**：CPI≈$1.18 最低、下载最多（192 万），但 FD 率 2.75%、RD 率垫底，ROI≈1.02 | CPI / FD 率对比 |
| ③ | **X 渠道持续恶化**：2026-03 起 CTR/FD 率逐月下降，2026-06 起加速恶化 | 月度趋势下钻 |
| ④ | **TikTok 2026-06 CPM 跳涨**：竞价成本涨约 40%，CPI 从 $0.71 抬到 $1.01 | 月度 CPI 对比 |
| ⑤ | **web 承接端 RD 占比高**：web 的 RD/FD 比 0.44 > app 的 0.31 | 按 platform 分组 |
| ⑥ | **区域结构差异**：东南亚流量便宜但付费弱，北美付费能力最强（FD/RD 客单最高） | 按 region 分组 |
| ⑦ | **整体趋势**：12 个月投放规模增长约 45%，含周末上行与年末旺季季节性 | 月度趋势观察 |

### 6.2 端到端 /ask 运行详情

**测试问题**：对比 Meta、X、TikTok 三个投放渠道 2026 年以来的效果：花费、下载量、FD 首次充钱用户数、RD 召回充钱用户数和 ROI，哪个渠道性价比最高？

**执行轨迹**：

```
Supervisor（意图路由）
  └→ 路由决策：data_analysis（问题涉及内部投放经营数据）

DataAnalyst Agent（数据分析）
  ├→ SQL 1: SELECT DISTINCT ad_channel FROM demo.channel_daily_metrics（确认渠道列表）
  ├→ SQL 2: 按渠道聚合 2026 年以来总花费/下载/FD/RD/收入/ROI/CPI（核心指标查询）
  ├→ 图表 1: Meta、X、TikTok 渠道总花费与总收入对比（柱状图）
  ├→ 图表 2: Meta、X、TikTok 渠道 ROI 对比（柱状图）
  └→ 图表 3: Meta、X、TikTok 渠道成本效率对比（柱状图）

Synthesizer（综合结论）
  └→ 结论生成完成（含引用标注 [1]）
```

**Agent 输出结论（摘录）**：

> 核心结论：基于 2026 年至今的数据，Meta 渠道的性价比最高，其 ROI 为 1.37，是唯一实现盈利的渠道。TikTok 渠道主要优势在于以极低成本拉新，ROI 接近持平（0.99）。X 渠道的整体表现最差，性价比最低。

| 指标 | Meta | TikTok | X |
|---|---|---|---|
| 总花费 (USD) | 2,615,696 | 1,596,820 | 636,440 |
| 总下载量 | 431,404 | 1,307,051 | 54,391 |
| FD 用户数 | 24,981 | 22,615 | 1,352 |
| RD 用户数 | 11,774 | 4,731 | 103 |
| ROI | **1.37** | 0.99 | 0.19 |
| 单次下载成本 | 6.06 | **1.22** | 11.70 |
