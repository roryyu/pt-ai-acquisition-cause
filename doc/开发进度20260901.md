## 一、本次工作目标

借鉴开源多 Agent 知识图谱项目 **Understand-Anything**（UA）的机制，为**深度研究模块**引入**研究知识图谱**：跨研究沉淀实体/主题/报告节点与关系，让每次深度研究"站在历史结论之上"——规划与报告生成阶段注入图谱背景，研究完成后自动抽取结论回灌图谱，形成**可增量演进的研究记忆**。

产出顺序严格遵循要求：先完成详细设计并存档（`doc/深度研究知识图谱融合设计-Understand-Anything.md`，300 行），再进入实现。

## 二、核心改造内容

### 2.1 UA 机制 → 深度研究的映射

| UA 机制 | 深度研究模块落地 |
|---|---|
| 多 Agent 流水线（并行 worker） | 子问题证据收集由串行改为**并发 2 受限并行**（结果顺序稳定） |
| 结构 + 语义混合抽取 | 保留 LLM 结构化抽取（非代码库，无 Tree-sitter 场景） |
| 图谱即 JSON、可版本化 | `data/research-graph/knowledge-graph.json` 单文件 + 原子写 + 支持随时重建 |
| 增量更新（只处理变更） | 每次研究完成增量合并；`POST /api/v1/research/graph/rebuild` 全量重建 |
| 图谱消费（检索/问答/可视化） | 发起前检索注入 Planner/报告上下文；前端径向布局可视化面板 |
| graph-reviewer 图谱评审 | 软化为**报告引用完整性校验**（`dr_review` 步骤，不阻断） |

### 2.2 新增模块 `lib/server/research-graph/`（5 文件，490 行）

| 文件 | 职责 |
|---|---|
| `types.ts`（140 行） | 图/节点/边/研究引用/抽取补丁类型；`normalizeNodeLabel` 归一；`extractJson` / `parseGraphPatch` 严格容错解析（无合法内容返回 `null`，不抛错） |
| `store.ts`（181 行） | 图谱加载/原子落盘/损坏降级空图；`mergeGraph` 纯函数合并：实体按归一 label 去重、边按三元组去重并并集 `reportIds`、report→topic 自动补边；节点上限 500 自动裁剪 |
| `query.ts`（70 行） | `tokenize`（英文单词 + 中文 2-3 字滑窗）+ `queryGraph`（词元重叠打分召回节点与历史研究，无向量库依赖） |
| `review.ts`（50 行） | `verifyCitationIntegrity`：空引用 / 悬挂引用 `[n]` 检测（借鉴 graph-reviewer） |
| `extractor.ts`（49 行） | `GRAPH_EXTRACT_PROMPT` 驱动 LLM 从子问题发现 + 报告摘要抽取图谱补丁，失败返回 `null` |

### 2.3 深度研究工作流改造（`deep-research.ts`）

```
发起前：queryGraph 检索图谱背景 ──→ 注入 Planner + 报告生成（graphContextBlock，≤2000 字）
规划 → 【并发 2】子问题执行 → 交叉比对 → 流式报告
  → dr_review：引用完整性校验（issues 透出，不阻断）
  → dr_graph_update：LLM 抽取 → mergeGraph → 落盘（失败仅透出提示）
```

- 事件全部复用现有 `step` / `tool_call` 协议，前端 `AgentTimeline` 零改动
- `answer` 负载新增 `graphStats` / `review`，随 Question 持久化

### 2.4 Prompt 改动（`prompts.ts`）

| 新增/修改 | 内容 |
|---|---|
| `GRAPH_EXTRACT_PROMPT`（新增） | 抽取 3-8 实体 / 1-3 主题 / ≤8 关系，禁止编造与宽泛化 |
| `graphContextBlock`（新增，纯函数） | 命中组装为背景块，超长硬截断 |
| `PLANNER_PROMPT` | 有图谱背景时子问题须在历史结论上**向外延展**，不得原样重复 |
| `REPORT_PROMPT` | 综合分析须说明相对历史结论的**增量**（印证/修正/拓展） |

### 2.5 前端：图谱面板 + 放大弹窗（`components/research/GraphPanel.tsx`，388 行）

- 三层径向布局可视化（实体蓝 / 主题绿 / 研究紫），图例 + 节点/边统计
- **放大弹窗**（本次迭代二）：小图右上「放大」按钮（`Maximize2` 图标），全屏居中弹窗展示大画布（960×620，节点上限 10 研究 / 8 主题 / 30 实体，节点与字号放大）；支持点击遮罩 / `Esc` / 关闭按钮三种退出；大视图中点击研究节点**先关弹窗再回看**
- 视图逻辑抽取为 `GraphViewConfig`（`SMALL_VIEW` / `LARGE_VIEW`），`GraphSvg` 按配置渲染，小图大图零重复代码
- 「重建」按钮：一键全量重建图谱；研究完成后 `refreshSignal` 自动刷新

### 2.6 新增 API

| 路由 | 说明 |
|---|---|
| `GET /api/v1/research/graph` | 图谱数据（节点/边/报告引用时间倒序 + 统计） |
| `POST /api/v1/research/graph/rebuild` | 清空后按时间正序遍历全部已完成的 deep_research Question 逐个合并重建 |
